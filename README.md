# 도안사랑교회 홈페이지

대전 유성구 원신흥동 도안사랑교회 홈페이지입니다. GitHub Pages로 운영합니다.

## 구성

| 주소 | 내용 |
| --- | --- |
| `/` | 대문 (교회소개 영상, 목사님 영상 프로필, 모바일 바로가기) |
| `/welcome/` `/vision/` `/churchtime/` `/directions/` | 교회소개 (인사말, 비전, 예배시간, 오시는 길) |
| `/missionization/` | 사랑의 선교지 |
| `/album/` | 선교&전도 앨범 |
| `/story/` | 사랑이야기 |

사랑의말씀 메뉴(설교모음, J안나방송)는 유튜브 채널로 연결됩니다.

## 내용 고치는 법

페이지 HTML은 `_build/build.py`가 `_content/`의 글 파일과 `_build/content.json`(대문 영상, 주소, 연락처 등 사이트 설정)을 읽어서 만듭니다.
글은 아래 "글 올리기"의 관리 화면에서 고치면 되고, 저장하면 GitHub이 자동으로 다시 만들어 올립니다.
컴퓨터에서 직접 만들어 볼 때는 다음 명령을 씁니다. (pyyaml, pillow 필요)

```
python3 _build/build.py
```

- 사진: `assets/img/album/<글번호>/`, 앨범 목록 썸네일은 `assets/img/thumbs/<글번호>.jpg`
- 인사말 등 이미지 페이지: `assets/img/pages/`
- 디자인: `assets/css/style.css`

## 글 올리기 (관리 화면)

사랑이야기, 선교&전도 앨범, 대문 행사 알림은 관리 화면에서 고칩니다.

1. https://app.pagescms.org 에 들어가 로그인합니다. (목사님 GitHub 계정, 또는 이메일로 초대받은 분은 초대 메일의 링크)
2. 도안사랑교회 저장소를 고르고 왼쪽에서 사랑이야기, 앨범, 행사 알림 중 하나를 고릅니다.
3. 새 글을 만들거나 기존 글을 고친 뒤 저장합니다.
4. 1~2분 뒤 홈페이지에 반영됩니다. (GitHub의 Actions 탭에서 진행 상황을 볼 수 있습니다)

- 본문은 한 줄이 한 문단이 됩니다.
- 사진은 휴대폰 원본을 그대로 올려도 됩니다. 홈페이지에는 자동으로 줄인 사진이 나갑니다.
- 행사 알림은 행사 날짜가 지나면 대문에서 저절로 사라집니다. (매일 0시 10분에 다시 정리)

### 파일 구조

- `_content/story/*.md` 사랑이야기 (글마다 한 파일)
- `_content/album/*.md` 앨범 (글마다 한 파일)
- `_content/events/*.yml` 대문 행사 알림
- `assets/img/uploads/` 관리 화면으로 올린 사진 원본
- `.pages.yml` 관리 화면 설정
- `.github/workflows/deploy.yml` 저장하면 페이지를 만들어 올리는 자동 작업
